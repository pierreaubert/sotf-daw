# Noise-fraction regularization: rejected candidate

Base: `21806c0`. This was a separately predeclared combined hypothesis after the natural-DD-only candidate was rejected. It did not use MCRA p, whose noise false-presence diagnosis is preserved in `remaining-denoiser-presence-risk-20261024`.

For modeled source/noise ratio xi and existing strength C, the candidate minimized the declared surrogate risk xi(1-g)^2+g^2+(C-1)/(1+xi)g^2. It therefore used effective strength 1+(C-1)/(1+xi), together with private natural-Wiener DD clean-power prediction. This is an SNR-dependent regularizer, not an MMSE or calibrated speech-posterior claim. No user parameters or noise/profile estimator were changed. The issue-9 plan, independent f64 reference, all source snapshots/hashes and raw data were frozen before guard analysis.

Independent checks passed: 40 f64 quadratic-risk optima/limits/monotonic cases (maximum gain error 4.8610e-8), 240 clean-power recurrence cases (maximum scaled error 1.6873e-7), exact application-control state invariance, 720 original independent DFT component checks, 144 noise-ranked records including 128 active pre-gain DFT checks, and all 48 zero-depth transfer cases. These checks do not establish perceptual quality.

The candidate failed the unchanged vowel gate in both modes: projection 0.322626/0.480574 versus required 0.5. One of 36 development full-source SDR rows regressed by 0.311379 dB, exceeding the 0.25 dB limit; the full signed range was -0.311379 to +4.009374 dB. Original settled gentle-noise checks stayed exact.

Crucially, four newly predeclared noise-step windows failed the same 1 dB attenuation-regression guard. The worst quality-mode noise-only step window changed from -19.7795 dB attenuation to -5.69293 dB, 14.0866 dB worse. Low latency changed from -19.5772 to -7.82872 dB, 11.7485 dB worse. This stronger independent control prevents accepting better speech metrics at the cost of passing more nonstationary noise. The old assertion was not rewritten. The original recorded/onset/zero integration targets were then run separately so all declared quality guards could be evaluated despite the library failure. `analysis.json` and `analyze.py` retain every signed quality/noise delta. `validation.json` and `quality-validation.json` are the raw runs, `baseline-noise-step.json` freezes the additive noise guard before candidate measurement. This isolates a substantial estimator-feedback contribution; it cannot be assumed safe merely because its state is independent of user controls. `ablation-analysis.json` retains all 12 windows and signed factor differences.
