# Native foundation protocol

No learned model or classifier training is introduced. The native public capture,
persisted profile, strict QA compatibility and full public drain define the
qualification boundary for later learned proposals. Existing production defaults,
profile compatibility and DSP are unchanged.

Independent capture reference: exact-mapped one-pole high residual and mean raw
one-sided squared DFT bins over full1024-point periodic-Hann windows,256hop.
The same documented convention is implemented in a separate Python/SciPy path
for tests, and direct recurrence/complex DFT for final artifact analysis. This is
validation of native capture math, not a claim that signal features identify
noise-only semantics.

Capture/noise seeds20691026/20701026; sample rate48kHz, capture1second,
programme3seconds, sigma0.003. Programme speech uses the existing attributed
single-speaker fixture repeated three times. No weights, new recordings or audio
assets are committed. Data are development material, not new held-out evidence.

Initial threshold-60 experiment is retained. Its near-zero spectral noise
suppression motivated reporting the explicit native minimum/default threshold
grid[-60,-30] rather than assuming profile validity implies reduction. All
settings/results remain visible; no threshold or model was selected from it.
Measured programme damage and native suppression must both be assessed before
promoting an interval proposal or claiming improvement.
