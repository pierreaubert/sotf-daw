Minimum-phase ordered target clarification: T composes each independent ideal band magnitude with the unit phase of that final actual FIR stage. The accuracy criterion therefore qualifies sampled magnitude and the complete cascade given actual stage phase, not equality to IIR/allpass phase and not a new minimum-phase proof. Zero actual stage magnitude with nonzero target still fails its magnitude check. Linear-phase target keeps positive ideal magnitudes after removal of the actual N/2 stage delay. Existing minimum-phase energy/latency tests remain unchanged.
