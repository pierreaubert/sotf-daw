# Independent XTC finite EOS / AUD093 review

2026-09-28. Read-only review; no source edits or Cargo runs. TokenSave entry-point discovery followed by current source inspection and comparison against the retained pre-EOS source at `/tmp/sotf-xtc-generation-race/src/lib/xtc_plugin.rs`.

## Findings

**No introduced blocker found in the reviewed scope.**

- **Ordinary audio extraction preserves arithmetic and cadence.** Text comparison from the loudness-measurement block through final denormal flushing is identical except disabled `return Ok(context.num_frames)` becomes the helper's `return`. The public process method still returns the accepted frame count. STFT scheduling, inverse filtering, gain measurement every tenth callback, compensation, limiter, channel routing and output timing are unchanged. Current references: `xtc_plugin.rs:1337-1482`, public preflight/adoption at1855-1908.
- **Enabled audio clock and EOS state are coherent.** Only enabled accepted frames advance phase; disabled routing retains the existing pause/resume wet history. Disabled EOF freezes the stream with zero output, preventing later toggles from making suppressed wet state audible. Empty EOF remains reusable. Nonempty EOS rejects changed controls/new input, while unchanged snapshots and empty process calls are no-ops. Reset clears enabled phase, EOS latch, cache and all relevant audio scheduling buffers; it retains settings and permits the next epoch. References:1823-1852,1892-1907,1940-1995.
- **No drain-driven filter adoption.** The extracted helper does not call `adopt_pending_filters`. A ready or late publication therefore cannot replace the active filter during drain. Existing active crossfades continue as ordinary zero continuation; completed previous snapshots transfer to bounded retirement with `try_lock`, retaining ownership when the lock or slots are unavailable. Reset finishes/retire-transfers the old fade without deleting pending desired work. Adoption occurs only after successful validation of a nonempty ordinary callback. References:969-1033,1327-1334,1823-1900; exercised by `src/lib/drain_tests.rs:238-322`.
- **Cache ownership and bound are consistent.** Constructor cache sizes derive from H and the actual constructed output width; geometry changes cannot enlarge them. Drain temporarily moves the prepared vectors, performs an infallible validated refill, then restores them before serving samples. Returned progress decrements the cache-inclusive remainder; unread cache is charged as a separate call in the query. No vector resize, filter destruction, publication polling or new measurement occurs when merely serving a partial cached hop. The canonical-H AutoGain/limiter comparison uses identical ordinary histories and an ordinary-zero process reference (`drain_tests.rs:172-208`), appropriately proving destination-partition independence rather than claiming normal callback independence.
- **Generation invalidation closes the demonstrated race.** Successful synchronous installation increments generation after the new filter passes width validation and stamps the active bundle. Even a worker already past its own generation check is rejected by callback adoption's current-generation check. Available/full retirement tests retain the stale payload without destruction and preserve the synchronous snapshot. References:807-826,894-906,969-1002 and `generation_tests.rs:50-156`.
- **Real width and rate contracts remain intact.** Recommended matrices require at least two output speakers (`load.rs:109`); constructor buffer sizes use the loaded matrix output count (`xtc_plugin.rs:462-465,512-551`), and actual two/four-output nonidentity tests load artifacts through that constructor. Async requests preserve expected width; synchronous install and adoption independently reject a different width. Source/artifact controls remain structural. The new stereo-AutoGain rate preflight rejects before changing sample rate, generation or audio state; its condition matches whether the two-channel meter exists. No-AutoGain acceptance remains unchanged. References:797-805,939-957,1588-1658,1791-1820.

## Existing limits, already recorded by the implementation report

Hard-disabled audio still bypasses immediately while latency metadata reports N. Normal AutoGain cadence remains callback-dependent. Reset does not await asynchronous desired configuration. Synchronous file/load/width failures can still return from the existing void helper while initialize proceeds; that broader transactionality gap is not fixed by AUD093. None of these behaviors was introduced by the reviewed extraction/drain/generation patch, and this review does not extend its guarantees to those paths.
