# Experimental offline native-repair discriminator

This model is **not adopted for production**. It qualified harmful repairs on
legitimate impulses in the frozen final probe. Existing Declick defaults,
detection, interpolation, realtime behavior and latency are unchanged.

The optional offline experiment uses a 16 → 16 tanh → 1 sigmoid MLP (289 trained
parameters). It predicts whether a complete native repair group reduces local
squared waveform error under its synthetic training distribution. It does not
identify the semantic origin or perceptual audibility of a click. Only an entire
native group can be selected; all other samples retain the original input. No
new interpolation or arbitrary model-generated waveform is permitted.

Example, from repository root with NumPy/SciPy installed:

```sh
cargo build -p sotf-plugin-declick --bin qa-declick-render --features qa --release
python scripts/ml/declick_qualify.py --input input-float32.wav --model crates/sotf-plugins/models/declick-discriminator/model.json --model-sha256 91dbe0e86f545c61ad714539510e6afe4f13ee45c61982f76adbc6cd2b7d4e9f --renderer /path/to/qa-declick-render --output new-result-directory --work new-native-work-directory
```

Use a new output/work directory and float32 WAV. The CLI leaves the source file
untouched and writes `qualified.wav` plus a report. It hashes/parses the same
bounded WAV buffer and the same bounded model buffer. Native latency is removed
only after public EOF drain; output retains the original number of frames.
The QA renderer processes actual plugin callbacks/drain under allocation guards.
Its raw export includes the latency prefix and exact declared drain samples.
The renderer and training parameters must match the frozen experiment; no claim
is made for a different native detector revision.

Supported model domain: mono, 48 kHz, legacy fullband random mode, sensitivity 5,
linked channels, repair width zero, residual audition off. These fixed native
parameters are generated by the CLI, not selected by the model. Features use
real two-sided 2/10/40 ms context, native-group duration, normalized dry/repair
energy and derivative changes. Clean references are used solely for labels and
error measurement. Groups wider than 32 samples, insufficient real context,
normalized features outside ±12, unsupported rates/channels, unavailable models
and scores below threshold all retain the original dry group. Invalid model
hash/shape/finiteness falls back to original audio and reports the reason.
This policy is not a guarantee that an admitted group improves arbitrary audio.
The sample-rate/channel domain is an initial implementation limit; the full
Declick audit item still requires broader supported-material validation.

Training used 128 underlying synthetic background identities with click and
legitimate-percussion variants (242 supported native candidate groups), plus
32 separate development identities (64 groups). Checkpoint epoch 138 minimized
development BCE. The threshold grid selected 0.99: five beneficial development
repairs, zero harmful ones. This score is uncalibrated outside the generator.
A separate simple post/pre energy-tail veto is also recorded; unprocessed dry
and unconditional native repair remain explicit comparison baselines.

Final scoring froze model/threshold/protocol before generating 16 new background
identities with six event variants, plus unsupported rate/stereo shifts: 99
correlated synthetic probes. It accepted two beneficial and two harmful groups.
It preserved the tested longer-tail percussion and attacks, but barely retained
click repair. Click SSE totals: dry 51.9693, native 5.12695, learned 37.3938,
classical tail veto 45.7133. On legitimate isolated-impulse programmes, learned
repair caused SSE 14.7920 and peak error 1.80833. In those counterfactual pairs,
the observed input and native repair are bit-identical to the injected-click
case; opposite reference intentions are unavailable to an audio-only classifier.
Sixteen such pairs establish the identifiability limit, not population accuracy.
No training or policy was changed in response to the final results.

Synthetic waveform-error improvements on one transient family do not establish
music safety or listening benefit. No recordings, measured clean references,
real DAW/platform contention or controlled listener tests were supplied. Better
data/context, matched damage/repair tradeoffs and independent final material
are required before adoption. UI/review integration and live-worker use remain
out of scope for this offline prototype and open in the audit tracker.

Evidence: `audit/artifacts/ml-declick-native-20261025` and
`audit/artifacts/ml-declick-model-20261025`. Source, generated data identities,
portable weights and synthetic fixtures are GPL-3.0-or-later. No external audio
or model weights are redistributed. Training requires PyTorch; inference does
not. The exact training recipes/dependencies are frozen beside the model.

Primary literature motivating separation of detection and interpolation and
explicit false-alarm measurement:
- [Oudre, IPOL2015](https://www.ipol.im/pub/art/2015/64/).
- [Ciołek and Niedźwiecki, ICASSP2017](https://sigport.org/sites/default/files/docs/ICASSP2017%20final.pdf).
- [Özdoğru et al., 2025](https://link.springer.com/article/10.1186/s13636-024-00389-9).
The two-sided feature design and context lengths are engineering hypotheses;
these publications do not validate this model or its admission policy.
